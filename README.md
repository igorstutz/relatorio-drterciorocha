# Relatório do site · Dr. Tércio Rocha

Relatório do Google Analytics 4 do site novo, de 19 a 29 de outubro de 2026, publicado no GitHub Pages.

- `index.html` — a página publicada (gerada, não editar à mão)
- `dados.js` — foto dos dados do GA4, lidos pelo Windsor.ai em 30/10/2026
- `painel.html` — a página do painel ao vivo no Claude, de onde saem os gráficos
- `gerar.py` — monta o `index.html` a partir do `painel.html`: `python gerar.py painel.html`

Para atualizar o período, troque os dados em `dados.js` (e os textos do período em `gerar.py`), rode o `gerar.py` e faça push na `main`.
